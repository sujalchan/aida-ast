# AIDA Language for VS Code

Syntax highlighting for the `.aida` files generated by aida-ast. Files are recognized
automatically. Colors follow your active VS Code theme.

Highlights declarations, variable names, custom procedures, event hats, built-in
commands and reporters (including Pen), strings and escapes, numbers, booleans,
operators and `unknown` placeholders. Includes bracket matching, automatic closing
pairs and indentation using four spaces.

This is a declarative TextMate extension: no runtime code or dependencies are needed.
It provides highlighting, not parsing, execution, diagnostics or completion.

## Install

In VS Code, run **Extensions: Install from VSIX…** from the Command Palette and
select `aida-language-0.1.0.vsix` from this folder. Then open a `.aida` file.

Alternatively, from the repository root:

```sh
code --install-extension editors/vscode/aida-language-0.1.0.vsix
```

## Preview from source

Open `editors/vscode` as the workspace folder in VS Code and press **F5**. This
opens an Extension Development Host with `examples/highlighting.aida`.

Use **Developer: Inspect Editor Tokens and Scopes** to inspect highlighting.

## Package from source

With Node.js and npm installed:

```sh
cd editors/vscode
npx --yes @vscode/vsce package --no-dependencies
```

This creates an installable VSIX locally. Packaging does not publish the extension.
The generated VSIX is ignored by Git.

The grammar follows the syntax documented in `docs/aida.md` in the repository.
See VS Code's [syntax highlighting guide](https://code.visualstudio.com/api/language-extensions/syntax-highlight-guide)
and [packaging guide](https://code.visualstudio.com/api/working-with-extensions/publishing-extension)
for the underlying extension format and packaging tool.
